# shell-core

Учебно-практическая командная оболочка для UNIX-подобных систем, реализованная на C. Проект демонстрирует разбор командной строки, построение дерева команд, запуск процессов, конвейеры, перенаправления и базовое управление заданиями.

## Возможности

- встроенные команды: cd, pwd, export, unset, echo, exit, alias, history, type, which, kill, jobs, fg, bg, true, false;
- запуск внешних программ через fork/exec и поиск исполняемого файла по PATH;
- операторы последовательного и условного выполнения: ;, &&, ||;
- конвейеры через |;
- перенаправления stdin/stdout/stderr, append, heredoc и дублирование файловых дескрипторов;
- переменные окружения и специальные параметры оболочки;
- command substitution: $(...) и обратные кавычки;
- кавычки, экранирование и globbing;
- фоновые задания и базовые сигналы интерактивного терминала;
- опциональная интеграция с GNU Readline.

## Сборка

Минимальная сборка:

~~~bash
cc -std=c11 -Wall -Wextra -pedantic shell.c -o shell
~~~

С GNU Readline:

~~~bash
cc -std=c11 -Wall -Wextra -pedantic -DUSE_READLINE shell.c -lreadline -o shell
~~~

Если Readline не установлен, используйте минимальную сборку.

## Запуск

~~~bash
./shell
~~~

Примеры:

~~~bash
ls | grep ".c"
echo hello > out.txt
cat < out.txt
false || echo fallback
sleep 5 &
jobs
~~~

## Реализация и личный вклад

Основная реализация находится в shell.c. В коде используются POSIX-интерфейсы процессов и файловых дескрипторов: fork, exec, waitpid, pipe, dup2, open, close, chdir, сигналы и терминальный API. Разбор командной строки построен на токенах и узлах командного дерева; обработка поддерживает составные команды, конвейеры и перенаправления.

Проект является дополнительной демонстрацией практической работы с C, системными вызовами и UNIX-подобной средой. Проверка второго этапа сообщила об успешной компиляции и базовых сценариях конвейера, cd, логических операторов, дозаписи и кодов завершения. Это не означает полной совместимости с Bash или прохождения полного POSIX conformance suite.

В репозитории нет отдельной реализации на C++. Поэтому проект подтверждает практический опыт именно с C; отдельный уровень владения C++ по этому репозиторию оценить нельзя.

README перечисляет технические спецификации и документацию используемых API; он не утверждает, что каждый из этих документов был единственным или фактическим источником при написании исходного кода.

## Ограничения

Это самостоятельная учебная оболочка, а не полная замена bash, zsh или POSIX shell. Отдельные тонкости совместимости, обработки сигналов, job control, quoting и command substitution могут отличаться от системных оболочек. Проверенные базовые сценарии не следует трактовать как исчерпывающее тестирование всех комбинаций грамматики.
